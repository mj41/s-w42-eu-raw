Set up your Stackchan

Plug the robot into this computer with a USB-C data cable (the port on its head), then press the button. The page installs the firmware and connects the robot to its server.

This browser cannot talk to USB devices. Use Chrome or Edge on a computer (not a phone).

First, sign in

Your robot will belong to your account: only you can see and control it.

Sign in with GitHub or Google

Chrome asks which device to use: choose the one named USB JTAG/serial debug unit. Setting up takes about two minutes (four with the backup); keep this page in front meanwhile.
